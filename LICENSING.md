# Licensing

Lanternfolk is open source, with paid options for specific features later
(open core).

| Path | License | Why |
|---|---|---|
| everything, unless listed below | [AGPL-3.0-only](LICENSE) | Free to use, self-host, and modify. If you run a modified Lanternfolk as a network service, you must offer its source to the people using it. |
| `protocol/` | [Apache-2.0](protocol/LICENSE) | The wire contract. Anyone can build a client or integration under any license. |
| `ee/` (does not exist yet) | commercial, to be decided | Paid features. Code there will carry its own license file. |

Dependencies are MIT, BSD-3-Clause, or Apache-2.0, all compatible with AGPL-3.0.

## Contributions

Dual licensing (AGPL for the community, a commercial license for paid
tiers) works only if the project may relicense the code it receives. Until
a contributor agreement is chosen, outside contributions are accepted only
with an explicit agreement from the contributor.
